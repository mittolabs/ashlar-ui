# ashlar

The `ashlar` command. It copies [Ashlar UI](https://ui.ashlar.ke)'s components
into your app, where they are yours to change.

```sh
dart pub global activate ashlar
ashlar init
ashlar add button
```

It is the same command `ashlar_ui` installs, so either works, and every
command is documented at [ui.ashlar.ke](https://ui.ashlar.ke) and in the
[`ashlar_ui` readme](https://pub.dev/packages/ashlar_ui).
