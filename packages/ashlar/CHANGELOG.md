## Changes

`ashlar` is released together with `ashlar_ui`, at the same version, and installs the same
command. What changed in each version is in
[`ashlar_ui`'s changelog](https://pub.dev/packages/ashlar_ui/changelog) and in the
[releases](https://github.com/mittolabs/ashlar-ui/releases).

## 0.3.0

- On `ashlar_ui` 0.10.0: `ashlar add --overwrite` replaces only what you name, and asks
  before replacing a copy you changed. Jaspr support is withdrawn.

## 0.2.0

- On `ashlar_ui` 0.9.0: in a Jaspr project, `ashlar init` and `ashlar add` copy Ashlar UI
  for Jaspr.

## 0.1.0

- `dart pub global activate ashlar` installs the `ashlar` command, the same one `ashlar_ui`
  0.8.1 installs.
